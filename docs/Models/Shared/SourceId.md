# SourceId

A NoResponse source: github (GitHub accounts), phone (the phone lookup), breach (breach exposure), rdap (the email domain's registration), mx (the email domain's mail servers) or ipintel (IP intelligence).


## Values

| Name      | Value     |
| --------- | --------- |
| `Github`  | github    |
| `Phone`   | phone     |
| `Breach`  | breach    |
| `Rdap`    | rdap      |
| `Mx`      | mx        |
| `Ipintel` | ipintel   |
